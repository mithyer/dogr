Support

Dogr is made by one person and is still new. The quickest way to get help, or to tell me something is wrong, is the Send feedback button at the bottom of the app's Settings. It writes the email for you and attaches the facts that help me find the problem. You can also write to fb@dogr.dev.

What you need

  • An iPhone or iPad with iOS 17.5 or newer.
  • A Mac or Linux computer that runs Herdr (the Herdr TUI or herdr-core).
  • One command, run once on that computer, that sets up the small service Dogr talks to and the way to reach it. Open the Get started section of the home page for the command and the three steps.

Setting up

  1. On the computer, run the command from the home page. It asks how your phone will reach the computer, says what it is about to do and asks before it does it; --dry-run shows the plan and changes nothing.
  2. It prints a QR code and a link. In the app, tap Add a machine and scan the code, or paste the link.
  3. Pick how the phone reaches the computer: Tailscale, Tailcat, Iroh, SSH, your own HTTPS proxy, or the same Wi-Fi. The app shows the command for the one you pick. If the computer allows SSH, the app can also run the setup for you after you give it the login; when the app only runs the setup, that password is used once and not kept.

When it cannot connect

What you seeWhat to try
"Can't reach this machine"Is the computer awake and online? Run collie doctor on it; it checks the service and says what is wrong. If you use Tailscale, make sure it is on on the phone too. Then tap Try again.
The pairing code does not workA code works once and expires. Run collie pair on the computer for a new one.
The machine goes offline after a while on Iroh or TailcatThese can pass through a public relay, which can be slow or busy. Run your own relay (the home page says how), or choose another way to connect.
It worked yesterday, not todayThe computer may have restarted, or its address may have changed. Run collie status there, and add the machine again if its link changed.
The app warns that a computer's SSH key changedThat is the warning working. If you did reinstall that computer, trust the new key; if you did not, do not.

Everyday questions

How do I remove a computer?
Press and hold its card on the first screen, then choose Remove.
How do I update the service on the computer?
Run collie update there.
Does Dogr work without Herdr?
No. It is a remote control for Herdr, and it needs the service from the setup command next to it.
What does Dogr keep and send?
See the privacy policy. In short: nothing leaves your phone except the traffic to your own computers, and the feedback email when you send one.

Tell me what is wrong, or what is missing

Dogr needs polishing and every report helps. Use Send feedback in the app, write to fb@dogr.dev, or open an issue on GitHub. Please say what you did, what you expected and what happened.
