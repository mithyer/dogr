Dogr

Watch your terminal agents from your phone.

Dogr shows which of your coding agents is working, which one is waiting for you, and which one has finished. You read what it is doing and answer from anywhere. It is an iPhone app for Collie, the open-source web interface for terminal agents.

The iPhone app is not on the App Store yet.

Set up your computer

One command puts Collie on your Mac or Linux computer and shows a QR code for the app to scan:

curl -fsSL https://dogr.dev/setup.sh | sh

The script says what it is about to do and asks once before it changes anything. You can read it first. Options and how to undo everything are on GitHub.
